# 🤖 Customer Churn Prediction ML Dashboard

An end-to-end Machine Learning project that predicts customer churn using classification algorithms and provides an interactive dashboard built with Streamlit and Plotly.

The project includes data preprocessing, exploratory data analysis, machine learning model training, evaluation metrics, and real-time customer churn prediction.

---

# 📌 Project Overview

Customer churn prediction helps businesses identify customers who are likely to leave their services. This project uses the IBM Telco Customer Churn dataset to analyze customer behavior and predict churn probability.

The application provides an interactive dashboard where users can explore:

- Customer dataset insights
- Churn analysis
- Machine learning performance
- Model evaluation metrics
- Real-time churn prediction


---

# 🚀 Features

## 📊 Data Analysis Dashboard

- Dataset overview

- Feature visualization
- Interactive Plotly charts


## 🤖 Machine Learning Dashboard

- Model performance evaluation
- Accuracy score
- Precision score
- Recall score
- F1 score
- ROC-AUC score

Visualizations:

- Confusion Matrix
- ROC Curve
- Precision-Recall Curve
- Feature Importance

## 🔮 Customer Churn Prediction

Users can enter customer details and predict:

- Customer will stay
- Customer is likely to churn
